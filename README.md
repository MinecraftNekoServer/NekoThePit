# ThePitPremium

一个功能丰富的Minecraft空岛生存插件，提供了独特的空岛游戏体验。

## 依赖要求

### 必装依赖

以下插件必须安装，否则ThePitPremium无法正常运行：

- **ProtocolLib** (v5.3.0或更高版本) - 用于协议处理和数据包操作
- **Spigot/Paper** (1.8.8或兼容版本) - 插件运行的基础服务端

### 推荐安装

以下插件可以增强ThePitPremium的功能体验：

- **LuckPerms** - 权限管理
- **PlaceholderAPI** - 变量扩展支持
- **PlayerPoints** - 玩家积分系统
- **DecentHolograms** - 全息图支持
- **ViaVersion** - 版本兼容性支持
- **Redis** - 高性能数据缓存 (如果使用缓存功能)
- **WordEdit**
- **Citizens**

## 安装说明

1. 确保服务器运行兼容的Spigot/Paper版本
2. 安装所有必装依赖插件
3. 将ThePitPremium.jar放入服务器的plugins文件夹
4. 重启服务器以加载插件
5. 根据需要配置插件设置

## Java 21 运行说明

如果使用Java 21运行此插件，请在启动服务器时添加以下JVM参数以确保插件正常运行：

```
--add-opens=java.base/java.net=ALL-UNNAMED
```

例如：
```
java --add-opens=java.base/java.net=ALL-UNNAMED -jar paper.jar
```

这是由于Java 17+引入的模块系统限制，需要显式授权才能访问某些内部API。

## 注意事项

- 插件需要Java 17或更高版本运行
- 使用MongoDB时需要确保数据库连接正常
- 建议定期备份插件数据文件
- 某些功能可能需要额外的依赖插件才能完全发挥效果

## 特色功能

- 独特的空岛生存玩法
- 丰富的任务和活动系统
- 完整的经济和商店系统
- 多样的装备和附魔系统
- 玩家社交和团队功能
- 个性化徽章和宠物系统

## 指令列表

### 玩家指令

- **/option, /options, /opt, /setting, /settings** - 打开选项菜单。需要达到特定等级（5级或精通 0 级以上）才能使用，用于调整玩家的各种设置和偏好选项。

- **/view [玩家名]** - 查看其他玩家的资料。需要达到70级或精通1级以上才能使用。可以查看其他玩家的等级、精通、装备、属性等信息，有5秒的使用冷却时间。

- **/events** - 预览活动界面。需要是支持者或管理员才能使用，用于查看当前和未来的活动信息。

- **/show** - 物品展示功能。需要是支持者或管理员才能使用，手持物品后可向服务器所有玩家展示该物品，有60秒的使用冷却时间。

- **/tradeLimits** - 查看交易限制信息。显示玩家当前的每日交易限制状态，包括交易金额和次数限制，每日凌晨4点重置。

- **/trade [玩家名]** - 向其他玩家发起交易请求。需要双方都不在战斗状态，且发起方未超过每日的交易限制。玩家之间可以通过此指令进行物品和金币的交易。

- **/respawn, /spawn, /home, /back** - 传送回家。在非战斗状态下将玩家传送回出生点，传送过程中需要保持静止，否则会取消传送。

- **/iKnowIGotWiped** - 确认wipe状态。用于确认自己在被wipe（等级清零）后的状态，标记玩家已了解其被wipe的情况。

- **/killRecap** - 查看死亡回放。显示玩家最近一次死亡的详细信息，包括击杀者、伤害记录等数据，用于复盘战斗过程。

- **/cdk [CDK码]** - 使用CDK兑换码。输入有效的CDK码以兑换奖励，需要满足特定的等级和精通要求才能兑换对应的奖励。

- **/viewOffer [玩家名]** - 查看交易报价。接受其他玩家向你发送的交易报价，需要在非战斗状态下且未超过交易限制才能接受。

- **/offer [玩家名] [价格]** - 发送交易报价。手持物品后向其他玩家发送交易报价，对方可以接受以获得你的物品并支付你指定的金币。

- **/AuctionGui** - 打开拍卖行界面。只有在拍卖行活动开启时才能使用，用于参与拍卖行的竞拍和出售物品。

- **/cool** - 使用酷指令。需要解锁"cool_perk"天赋才能使用，显示服务器在线的所有高级玩家（有昵称或精通等级大于0的玩家）。

- **/openKingsQuestUI** - 打开国王任务界面。需要权限 "pit.kingquest.ui"，用于参与国王的特殊任务和挑战。

- **/openBakeMaster** - 打开烘焙大师界面。需要权限 "pit.kingquest.ui"，用于参与烘焙相关的特殊活动。

### 管理员指令

- **/setupPunchY [数值]** - 设置punch Y轴参数。需要权限 "pit.adin"，用于配置游戏中的特定数值参数。

- **/gacha** - 执行抽奖操作。需要奖池功能启用，让执行者进行一次抽奖。

- **/giveGacha [玩家名] [数量]** - 给予玩家抽奖次数。需要权限 "pit.admin"，为指定玩家增加指定数量的抽奖次数。

- **/gachaPreview** - 预览奖池内容。查看当前奖池的奖励内容和设置。

- **/checkGacha [玩家名]** - 查看玩家抽奖次数。需要权限 "pit.admin"，用于查询指定玩家拥有的抽奖次数。

- **/checkMaxHealth** - 检查最大生命值。需要权限 "pit.admin"，用于检查玩家的最大生命值设置。

- **/pitadmin changeItemInHand tier [数值]** - 修改手持物品的等级。需要权限 "pit.admin"，用于修改玩家手持物品的品级。

- **/pitadmin mythicHologram** - 创建神话全息图。需要权限 "pit.admin"，用于创建神话物品的全息显示。

- **/pitadmin chestHologram** - 创建箱子全息图。需要权限 "pit.admin"，用于创建箱子的全息显示。

- **/pitAdmin setkothloc** - 设置KOTH（King of the Hill）位置。需要权限 "pit.admin"，用于设置KOTH活动的位置点。

- **/addSquadsLoc** - 添加小队活动位置。需要权限 "pit.admin"，用于设置小队活动的位置点。

- **/addbhLoc** - 添加BH（Block Head）活动位置。需要权限 "pit.admin"，用于设置Block Head活动的位置点。

- **/auction** - 拍卖相关指令。用于管理拍卖行活动，包括开启/关闭拍卖、管理拍卖物品等。

- **更多管理员指令** - 详见源代码，由于管理员指令数量众多，此处仅列出主要指令。管理员指令还包括物品管理、玩家数据管理、服务器配置、活动控制、NPC管理等多种功能指令。

## 权限节点

- **pit.admin** - 管理员权限，用于执行各种管理指令和功能
- **pit.adin** - 特定管理权限，用于某些特定管理功能
- **thepit.admin** - 高级管理权限，用于执行关键管理操作
- **pit.kingquest.ui** - 国王任务界面权限，用于访问国王任务相关功能
- **thepit.supporter** - 支持者权限，用于解锁支持者专属功能
- **pit.kingquest.ui** - 国王任务权限，用于访问国王任务界面
